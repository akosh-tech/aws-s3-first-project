# aws-s3-first-project
My first AWS S3 beginner project demonstrates bucket creation, file upload, and secure access configuration using best practices.

## 👋 Overview
This is my first hands-on project using Amazon Web Services. I used Amazon S3 to create a storage bucket, upload a file, and understand how cloud storage works in real life.
This project helped me move from theory to actually doing things in AWS.

## 🧰 What I Used
* Amazon S3 (Simple Storage Service)

## 🎯 What I Was Trying to Learn
* How cloud storage actually works
* How AWS stores files securely
* What buckets and objects mean in real life
* How permissions affect access to files


## 🪣 What I Did Step by Step

### 1. Created an S3 Bucket
I created a bucket in AWS and chose a region. This bucket is basically like a container where files are stored.

### 2. Uploaded a File
I uploaded a simple file into the bucket. This helped me understand that files in AWS are called “objects” and they live inside buckets.

### 3. Security Settings
I left public access blocked and used AWS default security settings. This made sure my file is private and protected.


## 🔐 What I Learned
* S3 is just cloud storage for files
* Everything is stored inside buckets
* Files are private by default in AWS
* Security is handled through permissions, not just settings
* AWS automatically keeps data safe and replicated
